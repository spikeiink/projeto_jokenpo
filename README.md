#Jogo do Jokenpô (Android)

Esse é um projeto Android simples feito em **Java** que implementa o clássico jogo **Pedra, Papel e Tesoura (Jokenpô)**.

O jogador escolhe uma opção e o app sorteia a opção da máquina; então o resultado é exibido com base nas regras:
- Pedra ganha de Tesoura
- Tesoura ganha de Papel
- Papel ganha de Pedra

---

##Tecnologias usadas

Linguagem: **Java**  
IDE: **Android Studio**  
Build: **Gradle**  
Plataforma: Android (API mínima conforme configurado no projeto)

---

##Funcionalidades

Tela de escolha do jogador  
Resultado contra a máquina  
Feedback visual simples  
Interface básica para Android

---

##Como rodar o projeto

1. Clone o repositório:
2. Abra o projeto no Android Studio.
3. Aguarde o Gradle Sync terminar.
4. Execute em um emulador ou dispositivo Android conectado.
